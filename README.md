# Datariot

**Short videos with a point.**

Datariot is a video platform for ideas worth exploring: discover useful perspectives, examine the reasoning, and reply with your own video.

## Links

- [Web app](https://datariot.xyz)
- [About Datariot](https://info.datariot.xyz)
- [Discord community](https://discord.gg/SKWCux4bb)

## What’s inside

- A focused short-video feed for learning, discussion, and discovery
- Video replies and structured debate threads
- Orvelis, an in-app guide for exploring ideas and questions
- Profiles, reactions, saved videos, and creator tools

## Tech

React Native, Expo, TypeScript, Expo Router, Zustand, and Supabase.

## Getting started

```bash
git clone https://github.com/datariotdev/datariot-site.git
cd datariot-site
npm install
npm start
```

To run a specific target:

```bash
npm run android
npm run ios
npm run web
```

Create a local `.env` file with the Supabase values required by your environment. Never commit service-role keys or other secrets.
