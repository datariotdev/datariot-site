THE ORVELIS GUIDE

A short video.
A question worth following.

Orvelis is the AI inside Datariot. Start with an idea in a clip, ask what is behind it, and decide where your curiosity takes you next.

A useful video can leave you with more questions than answers. Orvelis helps you unpack the topic, explore another perspective and bring your own thinking into the conversation.

Beta foundation & planned features

Deep Dive and video Q&A are the foundation in the current beta. The five features marked Planned below show where Orvelis is headed. Their examples illustrate the intended experience; availability will be announced as each feature ships.

Start with Deep Dive

  1. Find an idea. Open a video that makes you curious.
  2. Open Orvelis. In the video options, choose Orvelis AI Deep Dive.
  3. Get your bearings. Read the summary, explore three key terms and browse suggested videos, articles or podcasts.
  4. Ask your question. Use the chat to ask for a simpler explanation, a concrete example or a closer look at an assumption.
A QUESTION YOU CAN ASK
“The video says correlation does not prove causation. Can you explain that with an everyday example?”

Keep asking follow-up questions in the same chat to explore the topic at your own pace.

In the current beta, Deep Dive uses the video's title and description as context. It may miss details in the spoken audio or visuals. Suggested resources need checking; an AI explanation is not proof that a claim is true.

01 / FOLLOW YOUR QUESTIONPlanned

You choose what comes next.

The planned continuation connects your question to an explanation and relevant Datariot videos. You can follow the part that matters to you, through different creators and perspectives.

  • Explain it more simply
  • Show a real example
  • Find a strong counterargument
  • How can I use this?
EXAMPLE SCENARIO
“I'm learning to code. Which parts of this video about AI and programmers actually affect me?”

Orvelis would explain the relevant tasks, then suggest clips showing practical examples and a different view. Ask another question to keep shaping the route.

Why it matters: your next video follows a question you chose. You can stay with an idea long enough to understand it.

02 / FIND THE MISSING CONTEXTPlanned

Look behind a confident claim.

Orvelis is intended to separate the claim, the evidence offered and the assumptions connecting them. The planned analysis would link concerns to the relevant moment in a clip, with original sources and human video replies where available.

EXAMPLE SCENARIO
“AI will replace all programmers in two years.”

A useful response would ask whether the evidence concerns one coding task or an entire profession, surface the original research if available, and show a relevant response from a developer.

Facts, interpretations and predictions should be distinguishable. Where sources are missing, disagree or leave the question open, Orvelis should make that uncertainty clear. A timestamped concern points you back to the clip so you can judge it in context.

Why it matters: you get a way to examine an argument and hear another perspective before deciding what you think.

03 / REMEMBER WHAT YOU LEARNEDPlanned

Find the idea you almost forgot.

The planned personal memory would let you search clips you saved, and your watch history if you choose to enable it, using the details you remember. Orvelis would return the relevant clip or moment and help reconnect it to related ideas.

EXAMPLE SCENARIO
“Find that video explaining why a periscope camera is not always better than a regular telephoto.”

Return to the explanation, revisit the original creator and collect related clips in a personal topic collection, such as “What I learned about cameras.”

You would choose whether to include viewing history in your personal memory. This feature is planned as an opt-in experience.

Why it matters: useful clips become something you can return to and build on.

04 / BUILD A VIDEO REPLYPlanned

Turn a reaction into a clear point.

The planned reply assistant would help you work out exactly what you agree or disagree with, find supporting evidence and make a short outline for your response.

EXAMPLE SCENARIO
“I disagree with the conclusion, but I can't explain why. Help me structure a 30-second reply.”

Orvelis would help you identify the disputed assumption and organize your own argument: state the claim, give one concrete reason or example, and explain the conclusion.

You review the evidence and record the reply yourself. Datariot's on-camera posting format keeps your voice and perspective at the center of the exchange.

Why it matters: you have a starting point for joining the conversation, even when recording your first response feels difficult.

05 / BRING A CLIP TO DATARIOTPlanned

Start with something you saw elsewhere.

The planned link workflow would let you bring a video URL and ask a specific question. Where the content is accessible and supported, Orvelis would help explain the claim and connect it to sources and discussions on Datariot.

EXAMPLE SCENARIO
“I saw this clip on another platform. What evidence supports its main claim?”

Explore the available evidence and related Datariot videos. A shareable explanation would give others a link to the full discussion and the sources behind it.

Support will depend on access to the original content. A private, deleted or otherwise inaccessible video cannot be treated as if Orvelis has watched it.

Why it matters: a question that started elsewhere can lead to a deeper conversation here.

System Overview

Datariot is a cross-platform educational short-video platform built with a modern mobile-first stack. It focuses on structured intellectual discourse and AI-guided synthesis of knowledge.

Tech Stack

Layer Technology
Frontend React Native + Expo (v50+)
Navigation Expo Router (File-based)
Backend Supabase (PostgreSQL, Auth, Storage)
AI Engine OpenAI GPT-4
State Zustand

Project Structure

The repository follows a monorepo-lite structure managed by Vercel subdomains.

/datariot
├── datariot-docs/    # This documentation site
├── datariot-info/    # Main landing page (marketing)
├── datariot-xyz/     # Production web build of the Expo app
├── src/              # Expo application source code
│   ├── app/          # Expo Router pages
│   ├── components/   # UI components
│   ├── lib/          # Utilities (Supabase, API clients)
│   └── constants/    # Global constants & Theme
├── vercel.json       # Routing & subdomain configuration
└── package.json      # Main project dependencies

Backend Setup (Supabase)

Follow these steps to initialize the database and services on Supabase.

1. Database Initialization

Execute the schema found in src/lib/supabase/schema.sql using the Supabase SQL Editor to create all necessary tables, relationships, and RLS policies.

2. Storage Buckets

Create a public bucket named videos for hosting video assets.

Operation Policy
SELECT Public (All)
INSERT Authenticated User
DELETE Owner / Admin

Database Schema

The core tables and their primary fields are detailed below. For the full OpenAPI specification, refer to full_db_schema.json.

Table Description
profiles User profiles, avatars, and logic scores.
videos Video metadata, URLs, and creator mapping.
debates Structured debate threads and logic scoring.
later_actions User "Watch Later" interactions.
leaderboard Calculated rankings for the Creator DNA section.

Environment Configuration

Configuration is managed via .env. Do not commit this file to version control.

EXPO_PUBLIC_SUPABASE_URL=https://[YOUR_ID].supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=[YOUR_ANON_KEY]
SUPABASE_SERVICE_ROLE_KEY=[SECRET_ROLE_KEY]
OPENAI_API_KEY=[OPENAI_KEY]

Vercel Rewrites

The platform uses host-based rewrites in vercel.json to serve content from directories based on the requested subdomain.

  • docs.datariot.xyz → /datariot-docs/
  • info.datariot.xyz → /datariot-info/
  • datariot.xyz → /datariot-xyz/
